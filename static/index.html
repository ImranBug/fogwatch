Connect the coach to Dota 2

  1. Open Steam → Library, right-click Dota 2 and choose Properties…
  2. On the General tab find Launch Options and type -gamestateintegration (keep anything already there, separated by a space).
  3. Close the window and start Dota 2. The waiting screen switches to the draft as soon as the game sends data. The coach's config file is already installed on this Mac (uv run tools.py install-gsi re-installs it).
